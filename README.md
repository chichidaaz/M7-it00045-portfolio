# M7 IT0043 Portfolio

## Project Title
**M7 IT0043 Portfolio**

## Overview
A static, one-page personal portfolio website created for the M7 IT0043 project. The website presents the owner's work and information through a responsive layout and interactive features. It is built using HTML, CSS, and JavaScript and is intended for deployment through InfinityFree shared hosting.

## Features
- One-page portfolio layout
- Navigation links to the Home, Projects, and Contact sections
- Responsive layout for different screen sizes
- Mobile navigation menu
- Light and dark theme toggle
- Project content displayed using JavaScript
- Contact form with client-side validation
- Theme and visitor settings saved using browser local storage

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- InfinityFree (shared hosting)

## Setup
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Make sure the project files are organized as follows:

   ```text
   project-folder/
   ├── index.html
   ├── css/
   │   └── style.css
   └── js/
       └── script.js
   ```

4. Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.
5. To publish the website using InfinityFree, upload `index.html`, the `css/` folder, and the `js/` folder into the hosting account's `htdocs/` directory.
